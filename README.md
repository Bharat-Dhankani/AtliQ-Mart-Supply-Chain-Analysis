# AtliQ Mart - Supply Chain Analysis 📊

A Power BI dashboard analyzing **AtliQ Mart’s supply chain performance** to optimize procurement, inventory, and supplier management.  

---

## 🚀 Project Overview
This report provides end-to-end insights into AtliQ Mart’s supply chain operations.  
It helps identify bottlenecks, track supplier performance, and ensure smooth order fulfillment.  

---

## 🔑 Key Features
- 📦 Inventory turnover & stock-out analysis  
- 🚚 Order fulfillment & delivery performance  
- ⏱ Supplier lead time and reliability tracking  
- 📈 Demand forecasting & procurement planning  
- 🔍 Interactive visuals for bottleneck identification
